# 队列、播放顺序与封面补全

## 调整队列

打开底部的播放队列，按住歌曲左侧的拖动手柄，上下拖动并在插入线位置松开。靠近列表边缘时自动滚动，也可以继续使用上下移动按钮。

本地排序不改变正在播放的歌曲。房间队列仅房主及被授予播放控制权的成员可编辑；服务端按歌曲 ID 插入目标位置并向成员广播，保留拖动过程中其他人添加的歌曲。本地队列在房间内保留，离开房间后继续使用。

## 播放模式

底部队列图标左侧的播放模式按钮提供：

- **顺序播放**：按队列播放，最后一首自然结束后停止。
- **单曲循环**：自然结束后重播当前歌曲；手动点击下一首仍会切歌。
- **随机播放**：从其他歌曲中随机选择下一首；队列只有一首时重复播放。

手动下一首在队尾回到队首。上一首沿当前队列回退。本地模式会保存到设置中；房间模式由服务端保存和广播，仅有播放控制权的成员可以修改，且不会覆盖个人的本地模式。

房间自动切歌沿用房主客户端的结束通知机制：房主需要在线播放。服务端通过歌曲 ID 和播放基准时间拒绝过期或重复的结束通知。使用新模式时，请同时更新服务端和参与房间的客户端。

## 补全封面

侧栏的 **管理工具 → 补全封面** 仅对有歌曲管理权限的管理员显示，接口也校验管理员权限。

1. 选择本地封面目录。扫描当前目录中的 JPG、JPEG、PNG、WebP，每张不超过 5 MiB，不递归扫描子目录。
2. 客户端读取服务器缺少单曲或专辑封面的条目，先匹配 `歌曲-歌手`，未匹配时再匹配 `歌手-歌曲`。比较忽略大小写及分隔符周围空格，歌曲名称中可以包含连字符。
3. 检查图片预览和匹配结果。同一名称存在多张图片时不自动选定；未匹配项可以从所选目录的图片列表中手动选择，也可以设为“不补全此项”。
4. 专辑单独列出，显示其歌曲匹配出的候选图片，必须单独选择专辑封面。
5. 点击“确认补全”后才逐项上传。弹窗显示进度与每项结果，失败项可重试；关闭弹窗不终止已经确认的任务，再次打开可查看结果。

补全不会修改歌曲、歌手或专辑名称，也不会覆盖已有封面。若其他管理员在预览期间已经补全，结果显示“已有封面，未覆盖”。歌曲封面和专辑封面分别保存，展示优先级沿用现有客户端：有专辑封面时展示专辑封面，否则展示单曲封面。

## 新增接口

无需数据库迁移，复用已有 `cover_hash`、`cover_format` 字段。

所有 HTTP 接口均需登录并有 `admin` 权限，返回 `ApiResult` 信封。

| 方法与路径 | 参数 | data |
| --- | --- | --- |
| GET `/api/cover-completion/songs` | `pageNum=1&pageSize=100`，最大 100 | `{total, list:[{id,title,artist,albumId,albumName,songMissing,albumMissing}]}` |
| GET `/api/cover-completion/albums` | 同上 | `{total, list:[{id,name,artist,coverUrl:null}]}` |
| POST `/api/cover-completion/songs/{id}` | multipart `file` 图片 | `{applied:true}`；已有封面则 `false` |
| POST `/api/cover-completion/albums/{id}` | multipart `file` 图片 | 同上 |

WebSocket 沿用 `{type,data}` 请求及带 `serverTime` 的响应信封：

| type | 请求 data | 广播 |
| --- | --- | --- |
| `PLAYBACK_MODE` | `{mode:"SEQUENTIAL"}`，也可为 `REPEAT_ONE`、`SHUFFLE` | 同类型，data 为完整播放状态 |
| `TRACK_ENDED` | `{songId,timestamp}`，timestamp 为最近播放状态的 `serverTimestamp` | 成功推进时广播同类型的完整播放状态；过期通知忽略 |
| `QUEUE_MOVE` | `{songId,beforeId}`，`beforeId:0` 表示队尾 | `PLAYLIST_UPDATE`，data 为排序后的歌曲 ID 列表 |

播放状态新增 `mode` 和递增的 `revision`，旧 Redis 状态缺少时分别默认 `SEQUENTIAL` 和 `0`。模式变化保留播放基准时间，通过 `revision` 防止旧 REST / SYNC 快照覆盖新模式。`TRACK_ENDED` 仅房主可发送，其余两种操作遵循现有房间控制权限。
